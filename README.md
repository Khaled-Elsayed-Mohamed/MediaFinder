# MediaFinder

## Overview
MediaFinder is an iOS application built with Swift that was created as a bootcamp project. This application provides users with a powerful and intuitive interface to discover and search for media content.

## Features
- Search for media content across multiple sources
- Browse and explore media collections
- User-friendly interface designed for seamless navigation
- Efficient data fetching and caching

## Tech Stack
- **Language**: Swift (99.1%)
- **Build System**: CocoaPods
- **Key Dependencies**:
  - **Alamofire** - Elegant networking library for HTTP requests
  - **IQKeyboardManager** - Automatic keyboard management for smooth UX
  - **SDWebImage** - Asynchronous image downloading and caching

## Installation

### Prerequisites
- Xcode 10.2 or later
- Swift 5.0 or later
- CocoaPods

### Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/Khaled-Elsayed-Mohamed/MediaFinder.git
   cd MediaFinder
   ```

2. Install dependencies:
   ```bash
   pod install
   ```

3. Open the workspace:
   ```bash
   open MediaFinder.xcworkspace
   ```

4. Build and run the project in Xcode

## Project Structure
- `MediaFinder/` - Main application source code
- `MediaFinder.xcodeproj/` - Xcode project configuration
- `MediaFinder.xcworkspace/` - CocoaPods workspace
- `Pods/` - External dependencies managed by CocoaPods
